## เรื่องคีย์ที่อยู่ในหน้าเว็บ — ปลอดภัย ไม่ต้องซ่อน

ในไฟล์ `index.html` มีคีย์ Supabase อยู่ 1 ตัว:

```
sb_publishable_WJ2m36sC0wzUxLHAUiE4kw_bhybHasU
```

**คีย์นี้ถูกออกแบบมาให้เปิดเผยได้** และตรวจสอบแล้วว่า:

- อ่านตารางไหนก็ไม่ได้ — ทั้ง `eligible`, `claims`, `config`, `check_log`
- เขียนตารางไหนก็ไม่ได้
- ทำได้อย่างเดียวคือเรียกฟังก์ชัน `preorder_check` และ `preorder_claim`
  ซึ่งตรวจสอบทุกอย่างที่ฝั่งเซิร์ฟเวอร์ก่อนตอบ
- ไม่มี Email หรือเบอร์โทรของใครไหลกลับออกมาทางคีย์นี้ได้เลย

**สิ่งที่ห้ามใส่ในไฟล์นี้เด็ดขาด:** `service_role` key และกุญแจ `export_secret`
(ตัวหลังอยู่ใน Script Properties ของ Apps Script เท่านั้น ไม่เคยอยู่ในโค้ดหน้าเว็บ)

## วิธีอัปขึ้น GitHub Pages

```bash
cd "_deploy-github"
git init
git add .
git commit -m "Flash Back Pre-Order — test build"
git branch -M main
git remote add origin https://github.com/<ชื่อบัญชี>/<ชื่อ-repo>.git
git push -u origin main
```

จากนั้นในหน้า repo → **Settings → Pages** → Source เลือก `main` / `root` → Save
รอสัก 1–2 นาที เว็บจะขึ้นที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ-repo>/`

**ตรวจก่อน push ทุกครั้ง** ว่าไม่มีไฟล์แปลกปลอมติดไป:

```bash
git status --short
```

ควรเห็นแค่ `index.html`, `assets/bg.webp`, `assets/logo.webp`, `.gitignore`, `README.md`
